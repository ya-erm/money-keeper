# История изменений

## 2.18.0 - 2026-09-06

### Добавлено

- Добавлено сжатие журнала: кнопка «Сжать журнал» на странице импорта и экспорта заменяет всю историю изменений на сервере одним снимком текущего состояния. Номера синхронизации устройств остаются действительными, отставшие устройства получают снимок при следующей синхронизации.
- Добавлены ручки `GET /api/v2/journal/compact` (размер журнала) и `POST /api/v2/journal/compact`.

### Изменено

- Локальные изменения, ожидающие загрузки, повторно применяются после входящих обновлений, чтобы их не перекрывали более новые данные с других устройств.
- Загрузка журнала повторяется один раз после получения обновлений, если другое устройство уже заняло тот же номер записи.

## 2.17.0 - 2026-09-06

### Добавлено

- В операции добавлено необязательное поле «Описание из банковской выписки». Оно показывается в дополнительных параметрах формы, участвует в поиске и отображается в списке во время поиска.
- В операции добавлен статус сверки с выпиской (`ok`, `mismatch`, `missing`), который заполняется скриптом сверки. Проблемы отмечаются значком в списке и поясняются в форме.

### Изменено

- Сверка сбрасывается при изменении даты, суммы или счёта проверенной операции и не копируется при копировании операции.

## 2.16.0 - 2026-09-06

### Добавлено

- Добавлена ручка `GET /api/v2/snapshot`, которая возвращает текущее состояние всех данных, свёрнутое из журнала на сервере.
- Добавлена поддержка заголовка `Authorization: Bearer <token>` для запросов к API, предназначена для скриптов и внешних инструментов.
- Добавлена страница «API токены» в настройках для создания и отзыва токенов.
- В импорт и экспорт JSON добавлены повторяющиеся операции.

### Изменено

- Загрузка журнала теперь возвращает `409 CONFLICT` вместо ошибки сервера, если номер записи уже занят.
